# Introducing Plinth

We're excited to announce the launch of **Plinth** - the ultimate open-source starter for building production-ready SaaS applications.

## Why Plinth?

Building a SaaS from scratch is time-consuming. You need to implement:

- Authentication and authorization
- Billing and subscriptions
- Multi-tenancy and organizations
- Admin dashboards
- And much more

Plinth gives you all of this out of the box, so you can focus on building your product.

## Features

### Authentication

Plinth uses **Better Auth** for secure authentication with support for:

- Email/password authentication
- OAuth providers (Google, GitHub)
- Two-factor authentication (2FA)
- Magic links
- Session management

### Billing

With **Stripe** integration, you get:

- Subscription management
- Usage-based billing
- Invoice generation
- Webhook handling

### Multi-Tenancy

Organization management with:

- Team invitations
- Role-based access control (RBAC)
- Custom permissions
- Organization settings

### Admin Dashboard

Built-in admin panel for:

- User management
- Organization oversight
- System health monitoring
- Analytics and reporting

## Getting Started

```bash
# Clone the repository
git clone https://github.com/yoni-crypto/plinth.git

# Install dependencies
pnpm install

# Set up environment variables
cp .env.example .env

# Run the development server
pnpm dev
```
